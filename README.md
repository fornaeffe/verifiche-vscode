# Verifiche per VS Code

Estensione in sviluppo per creare e modificare verifiche ed esercizi attraverso
l'editor testuale di Visual Studio Code, con anteprime e generazione di PDF.

I contenuti sono file Markdown e YAML conservati in una cartella dati separata.
Questo repository contiene il software; non contiene verifiche o esercizi privati.

## Stato

Repository inizializzato. L'implementazione dell'estensione non è ancora iniziata.

La licenza prevista per il software è GNU GPL versione 3; il testo della licenza
verrà aggiunto durante la preparazione dell'estensione.
